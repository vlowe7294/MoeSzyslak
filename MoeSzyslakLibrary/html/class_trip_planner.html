Detailed Description

Manages a collection of stops and exposes COM-accessible trip-planning functionality.

TripPlanner implements the TripPlannerInf::ITRIPPLANNER interface and provides:

  • Adding and retrieving stops
  • Executing commands
  • Returning computed or formatted results
  • Managing trip-level properties
  • XML output generation
