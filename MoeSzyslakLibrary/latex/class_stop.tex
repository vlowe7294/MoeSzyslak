\doxysubsection{Detailed Description}
Represents a single stop in a trip, including start location, distance, and fuel usage. 

This class implements a COM-\/style reference-\/counted object used by \doxylink{class_trip_planner}{Trip\+Planner}. Each \doxylink{class_stop}{Stop} stores basic trip metrics and provides simple setters and a formatted print method.
