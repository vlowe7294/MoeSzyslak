\doxysubsection{Detailed Description}
Represents a single diagnostic or test log entry containing text, timestamp, and memory usage information. 

\doxylink{class_log_entry}{Log\+Entry} implements the \doxylink{struct_i_l_o_g_e_n_t_r_y}{ILOGENTRY} COM interface and provides access to structured log data. Each entry stores a message, a timestamp, memory usage at the time of logging, and a return string used by command operations. Entries can be serialized to and from database tables.
