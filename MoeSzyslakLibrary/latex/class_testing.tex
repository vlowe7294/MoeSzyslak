\doxysubsection{Detailed Description}
Provides a complete automated testing framework for COM‑based components, including logging, verification, reporting, and subsystem‑specific test execution. 

\doxylink{class_testing}{Testing} implements the ITESTING interface and supports:\+
\begin{DoxyItemize}
\item Running subsystem tests by class ID
\item Logging messages with timestamps and memory usage
\item Loading and saving test data
\item Generating HTML and XML reports
\item Verifying values and HRESULTs 
\end{DoxyItemize}
